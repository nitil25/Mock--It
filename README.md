🚀 Mock-It — Custom JSON API Generator
Turn any JSON data into a working API endpoint in seconds.

Mock-It is a developer utility that allows frontend developers to create instant mock REST API endpoints by submitting JSON data. Instead of building a separate backend just to serve placeholder data, developers can paste their JSON, generate a unique URL, and immediately use it in their applications.

✨ Features
Instant API Generation: Create a unique API endpoint from your JSON data.
Persistent Storage: Store JSON payloads in MongoDB.
Unique Endpoints: Generate unique IDs for individual mock APIs.
REST API Support: Retrieve saved JSON data using standard GET requests.
Automatic Expiration: Mock APIs automatically expire after seven days.
Simple Integration: Use generated endpoints with React, Vue, Angular, Postman, or any HTTP client.
JSON Flexibility: Store nested objects, arrays, strings, numbers, and other JSON values supported by the backend.
🎯 Why Mock-It?
Frontend developers often need API data before the actual backend is ready. Creating a temporary server for every project takes time and adds unnecessary complexity.

Mock-It simplifies this process:

Paste your JSON data.
Generate a mock API endpoint.
Copy the generated URL.
Fetch the data from your frontend application.
No need to build a separate API for every set of placeholder data.
